REST API для інтеграції

Усі запити потребують заголовка X-API-Key. Відповіді у форматі JSON. {% if api_key %}Поточний ключ: {{ api_key }}{% else %}Ключ видає адміністратор.{% endif %}

МетодШляхОпис
GET/api/orders?status=in_transitСписок замовлень з фінансами, фільтр за статусом
GET/api/orders/<id>Замовлення: дані, кошторис, історія статусів
PATCH/api/orders/<id>/statusЗміна статусу: {"status": "in_port"} (через change_order_status)
GET/api/cars?make=toyotaАвто з пошуком за маркою/моделлю
POST/api/clientsСтворення клієнта, серверна валідація (422 при помилках)
GET/api/statsЗведена статистика

Приклад (PowerShell)

curl.exe -s -H "X-API-Key: <ключ>" http://localhost:5000/api/orders/11

Коди відповідей: 200/201 успіх, 400 некоректний запит, 401 невірний ключ, 404 не знайдено, 409 конфлікт із правилами бази даних, 422 помилки валідації.
