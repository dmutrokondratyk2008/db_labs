RESTful API

Усі відповіді у форматі JSON. Користувач, від імені якого виконується дія, передається заголовком X-User-Id (спрощення замість автентифікації). Коди: 200/201 - успіх, 400 - некоректні дані або порушення $jsonSchema, 403 - немає прав, 404 - не знайдено, 409 - конфлікт (версії, унікальний індекс).
