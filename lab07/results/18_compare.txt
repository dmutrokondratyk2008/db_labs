MongoDB 9.0.8 (blog_bench)  vs  PostgreSQL 17.11 (blog_system.blog)

=== 1. Перевірка еквівалентності результатів ===
  збігається | Топ-5 авторів (username, кількість): MongoDB user13:71 user206:66 user194:65 user160:65 user148:63 | PostgreSQL user13:71 user206:66 user194:65 user160:65 user148:63
  збігається | Пости з тегами mongodb і nosql: MongoDB 1199 | PostgreSQL 1199
  збігається | Коментарів до опублікованих постів: MongoDB 109016 | PostgreSQL 109016
  збігається | Повнотекстовий пошук "docker": MongoDB 319 | PostgreSQL 319

=== 2. Читання (мс на запит: медіана / 95-й перцентиль) ===
  Q0 Порожній запит (мережа + драйвер): ping / SELECT 1
      MongoDB 0.151 / 0.233   PostgreSQL 0.340 / 0.453   швидше MongoDB у 2.3 раза  (n=300)
  Q1 Сторінка посту з автором, категорією, тегами і коментарями
      MongoDB 0.266 / 0.380   PostgreSQL 1.189 / 1.427   швидше MongoDB у 4.5 раза  (n=300)
  Q2 Стрічка категорії: 10 нових з кількістю коментарів
      MongoDB 0.337 / 0.460   PostgreSQL 0.791 / 0.936   швидше MongoDB у 2.3 раза  (n=300)
  Q3 Сторінка автора: 10 останніх постів
      MongoDB 0.297 / 0.425   PostgreSQL 0.457 / 0.549   швидше MongoDB у 1.5 раза  (n=300)
  Q4 Пошук за двома тегами одночасно
      MongoDB 0.357 / 0.598   PostgreSQL 2.185 / 3.212   швидше MongoDB у 6.1 раза  (n=200)
  Q5 Повнотекстовий пошук, 10 найрелевантніших
      MongoDB 3.477 / 13.350   PostgreSQL 13.090 / 266.714   швидше MongoDB у 3.8 раза  (n=100)
  Q6 Пагінація: випадкова сторінка 1-100 + загальна кількість
      MongoDB 37.495 / 42.498   PostgreSQL 8.731 / 9.569   швидше PostgreSQL у 4.3 раза  (n=200)
  Q7 Топ-10 авторів (агрегація всіх постів)
      MongoDB 28.759 / 31.496   PostgreSQL 6.311 / 12.136   швидше PostgreSQL у 4.6 раза  (n=40)
  Q8 Статистика коментарів (загальна, середня, максимум)
      MongoDB 52.859 / 55.910   PostgreSQL 19.747 / 21.496   швидше PostgreSQL у 2.7 раза  (n=40)
  Q9 Популярні категорії
      MongoDB 18.200 / 20.892   PostgreSQL 2.342 / 2.656   швидше PostgreSQL у 7.8 раза  (n=40)

=== 3. Запис (мс на операцію: медіана / 95-й перцентиль) ===
  W1 Додати коментар до посту
      MongoDB 0.299 / 0.382   PostgreSQL 1.002 / 1.085   швидше MongoDB у 3.4 раза  (n=300)
  W2 Лайк: інкремент лічильника посту
      MongoDB 0.250 / 0.302   PostgreSQL 1.018 / 1.122   швидше MongoDB у 4.1 раза  (n=300)
  W3 Перейменувати автора (денормалізоване ім'я)
      MongoDB 5.162 / 6.074   PostgreSQL 1.965 / 2.084   швидше PostgreSQL у 2.6 раза  (n=20)
      (W3: у MongoDB перейменування змінює документ користувача і 93 документів постів з копіями імені; у PostgreSQL - 1 рядок)

  Умови запису: PostgreSQL synchronous_commit=on (кожен COMMIT чекає запису WAL на диск), shared_buffers=128MB;
  MongoDB (окремий сервер, не набір реплік): writeConcern {w: 1}, журнал скидається на диск пакетно (до 100 мс).

=== 4. Обсяг зберігання ===
  MongoDB:    дані (без стиснення) 68.8 МБ, на диску (WiredTiger, snappy) 54.2 МБ, індекси 29.2 МБ
  PostgreSQL: таблиці (з TOAST) 84.4 МБ, індекси 27.9 МБ
